Task 1: Responsive Typography Demonstration

Media queries allow developers to apply CSS styles depending on device characteristics such as viewport width. As the screen size shifts between mobile (<600px), tablet (600px–992px), and desktop (>992px), font sizes for headings and paragraphs adapt dynamically to preserve readability and optimal line length.

Resize your browser window or switch to device emulation mode in DevTools to observe the typography fluidly scaling across the defined breakpoints.
