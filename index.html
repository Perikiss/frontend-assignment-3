Task 3 & 4: Responsive Grid (2 Columns)

Modular Layouts

Using Bootstrap's 12-column grid system, content reflows effortlessly. On mobile, this column occupies the full 12 units (`col-12`), while on medium and large viewports it neatly divides the row in half (`col-md-6 col-lg-6`).

Bootstrap Spacing Utilities

Margins and paddings rely exclusively on utility classes such as mb-4, p-4, p-md-5, and g-4, removing the need for custom spacing in external stylesheets.
